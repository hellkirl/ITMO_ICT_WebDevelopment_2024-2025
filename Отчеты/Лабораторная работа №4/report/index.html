    Отчет

    Общая структура проекта

    Проект состоит из нескольких основных директорий:

    src/ — содержит все компоненты и вспомогательный код;

    public/ — статические файлы для раздачи (HTML-макет, манифест, фавикон);

    api/ — вспомогательные модули для взаимодействия с REST API (axios);

    types/ — пользовательские типы и интерфейсы для удобной типизации.

    Технологии и инструменты

    React + TypeScript

    Используется компонентный подход, строгая типизация для повышения стабильности и предсказуемости кода.

    React Router

    Реализована навигация, маршруты для разделов ("/patients", "/doctors", "/visits").

    Axios

    Предоставляет методы для отправки HTTP-запросов к серверному API. Внутри api.ts описана базовая конфигурация и перехватчики (interceptors).

    NPM

    Управление зависимостями и скриптами (npm start, npm run build).

    App.tsx

    Подключает Router, разграничивает доступ к закрытым и публичным страницам.

    tsconfig.json

    Настраивает компилятор TypeScript (paths, target, strict режим).

    package.json

    Содержит список пакетов, скрипты для разработки (npm start, npm run build).

    Компоненты

    1. Header.tsx

    • Описание: Верхняя навигационная панель приложения.
    • Технологии и реализации:
      • Навигация: Использует NavLink из react-router-dom для переходов между страницами.
      • Стилевое оформление: Реализовано с помощью CSS или CSS-in-JS библиотек.
      • Компоненты: Включает логотип, ссылки навигации, иконки профиля и настройки.

    2. Patients.tsx

    • Описание: Управление списком пациентов с возможностью CRUD-операций.
    • Технологии и реализации:
      • Состояние: Использует useState для хранения списка пациентов и состояния форм.
      • Загрузка данных: useEffect для получения данных с сервера при монтировании компонента.
      • Формы: Реализованы с использованием контролируемых компонентов и валидации.
      • API взаимодействие: Axios для взаимодействия с сервером (GET, POST, PUT, DELETE запросы).

    3. Doctors.tsx

    • Описание: Управление информацией о врачах, включая расписание и трудовые договора.
    • Технологии и реализации:
      • Формы: Добавление и редактирование врачей с валидацией полей.
      • Расписание: Использование календарных компонентов (например, react-calendar) для отображения расписания.
      • API взаимодействие: Axios для выполнения запросов к серверу.

    4. Visits.tsx

    • Описание: Организация и управление записями на приём к врачам.
    • Технологии и реализации:
      • Форма записи: Выбор врача, даты и пациента через контролируемые компоненты.
      • Проверка доступности: Отправка запросов на сервер для проверки свободных слотов.
      • Отображение визитов: Табличный вид с сортировкой и фильтрацией по дате и статусу.

    5. Schedule.tsx

    • Описание: Отображение календаря и расписаний врачей.
    • Технологии и реализации:
      • Календарь: Интеграция с библиотеками, такими как FullCalendar, для визуализации расписаний.
      • Фильтрация: Возможность фильтрации расписаний по дате и конкретному врачу.
      • Интерактивность: Возможность добавления и редактирования расписаний через интерфейс календаря.

    6. MedicalCards.tsx

    • Описание: Управление медицинскими картами пациентов.
    • Технологии и реализации:
      • CRUD-операции: Создание, чтение, обновление и удаление записей медицинских карт.
      • Связь с пациентами: Интеграция с компонентом Patients.tsx для отображения истории данных.
      • Форматирование: Использование редакторов формата Rich Text для ввода данных.

    7. Footer.tsx

    • Описание: Нижний колонтитул приложения с дополнительной информацией и ссылками.
    • Реализация: Статическая информация или динамические ссылки.
